# AGENTS.md

ReplyDNA's agent instructions live in **[CLAUDE.md](CLAUDE.md)** (daily routine, hard safety rules, commands) and
**[docs/SETUP_PROTOCOL.md](docs/SETUP_PROTOCOL.md)** (first-time setup). Any coding agent (Codex CLI, Gemini CLI,
Cursor, Windsurf, …) can follow them: read both files first, then act exactly as they describe.

The project is built and tested with **Claude Code**. Other agents should work for the script-driven steps;
quality of voice-matched replies depends on the model.
