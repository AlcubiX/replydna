# Security policy

ReplyDNA runs on the creator's own computer and talks to the YouTube Data API with the creator's own OAuth login.
Tokens live in `secrets/` (git-ignored) and are never sent anywhere except Google.

## Reporting a vulnerability
Please **do not open a public issue**. Email **hello@alcubix.com** with the details and steps to reproduce.
We reply within 2 working days and credit reporters who want it.

## Supported versions
The latest release on `main` receives fixes.
